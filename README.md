# NextGPA AI — Academic Performance Predictor

NextGPA AI is a full-stack machine learning web application built with **React.js**, **FastAPI**, and **PostgreSQL**. It analyzes academic trends and predicts student GPA performance using a 15-feature machine learning model.

##  Key Features
* **GPA Prediction Engine:** Utilizes an ML regression pipeline to deliver accurate target grade forecasts.
* **Subject Diagnostic Advisor:** Highlights weak subjects and suggests optimized study time allocation.
* **Interactive Dashboard:** Clean UI built for students to visualize performance trends over time.

##  Tech Stack
* **Frontend:** React.js, Tailwind CSS
* **Backend:** Python, FastAPI, Uvicorn
* **Database:** PostgreSQL
* **Machine Learning:** Scikit-learn, Pandas, NumPy
